# API de Auditoria

O app expõe endpoints DRF para monitoramento e execução.

## Rotas atuais

- `checkpoints/`
- `execucoes/`
- `sinc_rec/health/`

## Capacidades principais

- listar checkpoints
- listar execuções
- detalhar execução
- listar tabelas lidas e escritas
- acionar execução de domínio
- healthcheck de sincronização
- monitoramento resumido e recente
